# Releasing Nourish to TestFlight

A working release flow without Xcode Cloud. Run `./release.sh` for the
automated path; the manual checklist below documents what it does.

## Prerequisites (one-time, already set up)

- Apple Distribution certificate in Keychain
  Verify: `security find-identity -v -p codesigning` → expect
  `Apple Distribution: Yael Schnarch (K623VDGZF8)`
- Provisioning profile `Nourish App Store` installed
  (in `~/Library/MobileDevice/Provisioning Profiles/` and
  `~/Library/Developer/Xcode/UserData/Provisioning Profiles/`)
- Transporter app installed from the Mac App Store

If a piece is missing, see "Re-creating prerequisites" at the bottom.

## Release checklist

1. **Bump the build number** (every TestFlight upload must have a unique build number)
   ```
   ./release.sh --bump
   ```
   Or, if you're cutting a new user-facing version too:
   ```
   ./release.sh --bump --version 1.1
   ```
   The script edits `CURRENT_PROJECT_VERSION` (build) and `MARKETING_VERSION` in
   `Nourish.xcodeproj/project.pbxproj`.

2. **Archive + export** — the script does this. It produces:
   - `/tmp/Nourish.xcarchive` (full archive)
   - `/tmp/NourishExport/Nourish.ipa`
   - `~/Desktop/Nourish.ipa` (copy for easy drag-into-Transporter)

3. **Upload via Transporter**
   1. Open Transporter, sign in with `yael.schnarch@gmail.com`
   2. Drag `~/Desktop/Nourish.ipa` into the window
   3. Click **Deliver**
   4. Wait for "Delivery Successful"

4. **Confirm in App Store Connect**
   - `appstoreconnect.apple.com` → Nourish → TestFlight tab
   - Build appears under "Processing" first, becomes available in 5–15 min
   - Add it to your tester group, send invites

5. **Commit the version bump**
   ```
   git add Nourish.xcodeproj/project.pbxproj
   git commit -m "Bump build to <build-number>"
   git push
   ```

## Manual command reference

If you want to run the steps yourself instead of using `release.sh`:

```
# 1. Archive
cd '/Users/yael.schnarch/Documents/Claude code tests/Xcode/Nourish'
rm -rf /tmp/Nourish.xcarchive
xcodebuild -scheme Nourish -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath /tmp/Nourish.xcarchive \
  CODE_SIGN_STYLE=Manual \
  CODE_SIGN_IDENTITY="Apple Distribution" \
  PROVISIONING_PROFILE_SPECIFIER="Nourish App Store" \
  archive

# 2. Export (uses ExportOptions.plist generated by the script — see release.sh)
rm -rf /tmp/NourishExport
xcodebuild -exportArchive \
  -archivePath /tmp/Nourish.xcarchive \
  -exportPath /tmp/NourishExport \
  -exportOptionsPlist /tmp/ExportOptions.plist
```

## Re-creating prerequisites

### Distribution certificate
1. `developer.apple.com/account/resources/certificates/list` → **+** → **Apple Distribution**
2. Generate CSR via Keychain Access (Certificate Assistant) or with openssl:
   ```
   openssl genrsa -out distribution.key 2048
   openssl req -new -key distribution.key -out distribution.csr \
     -subj "/emailAddress=yael.schnarch@gmail.com/CN=Yael Schnarch/C=US"
   ```
3. Upload CSR, download `.cer`, double-click to install in Keychain
   (If you used openssl, also: `openssl pkcs12 -export -inkey distribution.key
   -in distribution.cer -out distribution.p12` then `security import distribution.p12`)

### Provisioning profile
1. `developer.apple.com/account/resources/profiles/list` → **+** → **App Store** (under Distribution)
2. App ID: `com.yael.nourish`, certificate: `Apple Distribution: Yael Schnarch`
3. Name it exactly `Nourish App Store` (the script depends on this name)
4. Download and double-click
